🟦 3) NC‑Pipeline — Norm‑Dokument (X4‑1‑4‑Ebene)

Kein Segment darf Last oder Moves erzeugen.

Norm 2 — Linearität
Die Pipeline folgt einer festen Reihenfolge.

Norm 3 — Übergabe
Frames werden neutral übergeben.

Jedes Segment ist öffentlich sichtbar.

🟦 5) Narrativ (Erzählform)
Die NC‑Pipeline ist der neutrale Fluss des Systems.
Sie beginnt im Root, nimmt Form im Frame, öffnet Wege im Channel,
stabilisiert sich im Neutralraum, puffert im Buffer, entscheidet im Switch,
fließt im Flow, bündelt im Merge und endet im Exit.

Sie ist der Weg, den jedes Modul gehen kann, ohne Last zu tragen.

Sie ist die Geschichte der Neutralität.

→ Narrativ vertiefen
